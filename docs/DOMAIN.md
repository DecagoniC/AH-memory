# Предметная область

**Выбор: Вариант В** — база знаний учебного курса / энциклопедии предметной области  
(постановка, §5; аналог рис. 9 монографии — иерархии IS-A поверх учебного корпуса).

## Обоснование

- Junior-эталон «заяц» (монография §7, рис. 14) — учебный текст по окружающему миру.
- IS-A-иерархии естественно ложатся на энциклопедический корпус (животное → зверёк → заяц).
- Эпизоды H с FOLLOW можно моделировать как учебные «наблюдения» / сценарии урока без смены домена на Middle/Senior.
- Роли LOCATION / TIME / CAUSE доступны в описательных фактах («обитает в лесу», «зимой шерсть белая, потому что…»).

## Разделы AH под домен

| Раздел | Содержание |
|--------|------------|
| **S** | Лексика и понятия 1-го порядка: HARE, ANIMAL, FOREST, MEADOW, … + текстовые парадигмы R |
| **C** | Общие знания курса: таксономия, свойства классов, шаблоны предикатов (IS, LIVE_IN, HAVE, RUN, …) |
| **P** | Частные модели конкретных экземпляров (этот заяц, этот лес) — расширяется на Middle |
| **H** | Эпизоды: цепочки учебных фактов / наблюдений, связанные FOLLOW |
| **L** | IS-A, ассоциации символ↔символ 2-го порядка, прочие бинарные связи |

## Корпус (≥15 000 слов, Senior NFR)

- Источник: открытые учебные/энциклопедические тексты по теме «Животные / окружающий мир» (RU).
- Минимальный объём: **≥ 15 000 слов**.
- Целевое наполнение графа: **≥ 1000** гиперузлов+связей; **|S| ≥ 150** с непустым R.
- Расположение (после сборки): `data/corpus/` + дамп `data/ah_dump.json`.

Junior использует ручное наполнение кейса «заяц» без полного корпуса.
